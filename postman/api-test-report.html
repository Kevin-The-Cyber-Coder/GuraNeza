How to see this in Postman

  1. Import GuraNeza.postman_collection.json and GuraNeza.postman_environment.json into Postman.
  2. Select the GuraNeza Live environment in the top-right dropdown.
  3. Open the collection and click Run, then Run GuraNeza API — Lecturer Demo.
  4. The Login request stores the JWT in the token variable automatically, so protected requests pass.
  5. Every request has pm.test() assertions — the Runner shows green PASS or red FAIL.
Write operations: the collection also includes register/create/update/delete requests marked "⚠ WRITES DATA" for completeness. They were not executed against the live database — run them only on a test database.
